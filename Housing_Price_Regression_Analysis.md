# Housing Price Regression

**Question:** How do house size, number of bedrooms, lot size, and architectural style affect sale price?

**Data:** Cross-sectional observations of houses with price, assessed value, square footage, bedrooms, lot size, and a colonial-style indicator.

**Methods:** Summary statistics and OLS regression (including log transformations).

**Key variables:**  
- `price` / `lprice` — sale price (and log)  
- `sqrft` / `lsqrft` — square footage  
- `bdrms` — number of bedrooms  
- `lotsize` / `llotsize` — lot size  
- `assess` / `lassess` — assessed value  
- `colonial` — colonial-style indicator  

**Output:** Stata log showing descriptive statistics and regression results.
